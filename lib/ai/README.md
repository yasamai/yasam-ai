# Yaşam AI Decision Engine v5.1

Bu klasör Yaşam AI'nın tek karar çekirdeğidir. Arayüz, rapor ve API katmanları hesaplama yapmaz; bu modülü çağırır.

Akış: Değerleme → Kira → Veri Güveni → Risk → Likidite → Fırsat → Yatırım → Pazarlık → Nihai Karar → Açıklama.

Altın kural: Resmî tapu/imar teyidi ve en az üç doğrulanmış emsal yoksa güven skoru 58'i aşamaz ve karar `DOĞRULAMA BEKLİYOR` olur.
