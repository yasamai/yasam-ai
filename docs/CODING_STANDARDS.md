# Kod Standartları

- TypeScript strict davranışı korunur.
- Saf hesaplar React bileşenlerinden ayrılır.
- Bir modülün veri erişimi, iş kuralı ve görünümü ayrı tutulur.
- Yeni özellikler `feature/...` dalında geliştirilir.
- PR öncesi `npm run verify` zorunludur.
- Büyük dosyalar tek seferde değil, derlenebilir fazlarla bölünür.
- Gizli değer, kişisel veri ve test dışı gerçek müşteri verisi commit edilmez.
